Исправленная независимая версия сайта для GitHub Pages.

В комплекте:
index.html       — сайт с исправленным описанием одного тренажёра

.nojekyll        — служебный файл GitHub Pages

ВАЖНО: Ранее приложенное изображение concept-render.png было вымышленным и не
соответствовало реальной модели Train-X. Оно удалено полностью.

Как обновить репозиторий GitHub:
1. Откройте репозиторий trainx-site.
2. Загрузите все ТРИ файла из этой папки (включая скрытый .nojekyll) в корень репозитория.
3. При вопросе о замене файлов подтвердите перезапись index.html и trainx-3d.html.
4. Если раньше был загружен concept-render.png — удалите его из репозитория.
5. GitHub Pages: Настройки → Страницы → Развертывание из ветки main / (root).
6. Откройте опубликованный сайт в приватном окне.

На сайте есть только фактическая проектная 3D-модель, это не финальная
производственная документация; механизм пока проектный и не испытан.

Патентное внимание: детальный интерактивный 3D-просмотрщик будет публичным.
Уточните возможность раскрытия у патентного поверенного до публикации.
